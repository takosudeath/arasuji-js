ブックマークレット

サイトが arasuji.js に対応していなくても、ブックマークから「前回のあらすじ」を使えます。進捗はそのサイトごとに、このブラウザの中に保存されます。

登録のしかた

次のリンクをブックマークバーへドラッグします。

あらすじ

ドラッグできないときは、適当なページをブックマークしてから、その URL を次の文字列に書き換えます。

使い方

  1. 長文のページを開いて、ブックマークの「あらすじ」を押す
  2. ページの h1 の下に「前回のあらすじ」欄が入り、各節の末尾に「次の節へ」ボタンが入る
  3. もう一度押すと、あらすじを読み上げる

ページを再読み込みしたり、別のページへ移ったりしたときは、もう一度押してください。教材が iframe の中にあるサイトでは、次の教材へ移ったときももう一度押してください。

設定済みのサイト

次のサイトでは、本文の範囲と節の見出しを合わせてあります。ほかのサイトでは main の中の h2 を節として扱います。

サイトURL

使えないサイト

  • Content Security Policy で外部の script を止めているサイト（「読み込めませんでした」と出る）
  • 本文が main の中になく、h2 で節を分けていないサイト（「見出しが見つかりませんでした」と出る）
  • ページ移動で本文だけを JavaScript で入れ替えるサイト（2ページ目以降で節が合わない）

要約データはないので、あらすじは「どこまで・続き・残り」だけになり、要点は入りません。
